# Cognifyz Internship — Data Analysis

All 11 Data Analysis internship tasks are included across Level 1, Level 2, and Level 3.

## Structure
- Level 1: 4 tasks
- Level 2: 4 tasks
- Level 3: 3 tasks

Each task is stored in a separate Python file.

## Dataset
Place the supplied dataset at data/Dataset.csv or provide another CSV with --data.

## Setup
```bash
python -m pip install -r requirements.txt
```

Example:
```bash
python "Level 1/task_1_top_cuisines.py" --data data/Dataset.csv
```
